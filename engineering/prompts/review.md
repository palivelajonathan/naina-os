# NAINA OS Package Code Review Prompt

Every time Gemini finishes a package:

Review this package as a Principal Rust Engineer.

## Review Criteria:

- Architecture
- Performance
- Memory safety
- Thread safety
- Error handling
- API design
- Dependency violations
- Package rules
- Documentation
- Tests

## Return:

- Critical Issues
- High Issues
- Medium Issues
- Low Issues

If production-ready, state:

APPROVED
